# ZUZA'S DIARY — ACTION MESSAGES

Contextual toast/snackbar/dialog microcopy for successful user actions.

## Implementation rules

- Trigger messages only after the corresponding action succeeds.
- Main line should be suitable for a short toast/snackbar.
- Supporting line is optional for dialogs or larger confirmation surfaces.
- Rotate variants only within the same action category.
- Error states belong in the separate error/empty-state pool.
- Keep eggs contextual: the action must still be understandable without the joke.
