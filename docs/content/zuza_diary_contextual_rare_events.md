# ZUZA'S DIARY — CONTEXTUAL RARE EVENTS

Rare messages triggered by explicit, meaningful application conditions.

## Implementation rules

- Use local device time only. No API, server or cloud dependency.
- Each milestone event should normally appear once; persist a local shown-events registry.
- Annual events may recur once per calendar year.
- Rare random events must be genuinely rare and must never interrupt normal use.
- Trigger conditions must be transparent in code and easy to modify later.
- Do not invent new milestones without product approval.
